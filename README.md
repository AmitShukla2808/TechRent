# TechRent
TechRent is a comprehensive web-based platform designed to simplify the process of renting electronic devices. Whether you're looking to rent a laptop, TV, camera, Xbox, or other electronic devices, TechRent has got you covered with an intuitive and user-friendly interface.

## Features

### 1. **Product Filtering**
- Filter products by various criteria, including:
  - Brand or company.
  - Price range.
  - Condition (old, new, or good condition).
  - Ownership status.

### 2. **Product Details**
- View detailed features of each product.
- High-quality images for better visualization.
- Comprehensive specifications for informed decision-making.

### 3. **Rental Cost Calculation**
- Easily calculate the rental cost for any device with our built-in rental calculator.

### 4. **Device Renting Service**
- Rent your own device through the platform and earn.
- Seamless process for listing your devices.

## Technology Stack
TechRent is built using the following technologies:
- **Frontend:** React.js, HTML5, CSS3, JavaScript.
- **Backend:** Node.js, Express.js.
- **Database:** MongoDB.
- **Additional Tools:** REST APIs, JWT for authentication.

## Getting Started

### Prerequisites
To run the project locally, ensure you have the following installed:
- Node.js (v14 or higher)
- MongoDB (local or cloud instance)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/TechRent.git
   ```

2. Navigate to the project directory:
   ```bash
   cd TechRent
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Set up environment variables:
   - Create a `.env` file in the root directory.
   - Add the following variables:
     ```env
     PORT=5000
     MONGO_URI=your_mongodb_connection_string
     JWT_SECRET=your_secret_key
     ```

5. Start the development server:
   ```bash
   npm run dev
   ```

6. Access the application in your browser at `http://localhost:5000`.

## Usage
- **Browse Devices:** Use filters to find the perfect device for your needs.
- **Check Details:** View images and specifications of devices.
- **Calculate Rent:** Use the rental calculator to determine costs.
- **List Your Device:** Rent out your own electronics to earn extra income.
